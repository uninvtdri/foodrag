# Performance Comparison: Local vs Cloud RAG System

## Local System (Week 2)
- Vector DB: ChromaDB
- Embeddings: Ollama mxbai-embed-large
- LLM: Ollama llama3.2
- Average response time: 3-5 seconds
- Requires local machine to run

## Cloud System (Week 3)
- Vector DB: Upstash Vector
- Embeddings: BGE_SMALL_EN_V1_5
- LLM: Groq llama-3.1-8b-instant
- Average response time: under 1 second
- Accessible from anywhere via browser

## Conclusion
The cloud system is significantly faster and more accessible than the local version.
